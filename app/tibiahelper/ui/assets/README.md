# Ikony

- `github.svg`: ikona `mark-github` z [Primer Octicons](https://github.com/primer/octicons)
  (licencja MIT, Copyright (c) GitHub Inc.). Zmieniony tylko kolor wypełnienia.
  Używana wyłącznie jako link do zgłoszeń w repozytorium na GitHubie.
  `github-dark.svg` to ta sama ikona w ciemnym kolorze, dla jasnego motywu.
- `pin.svg`: pinezka narysowana dla TibiaHelper (MIT, jak reszta kodu).
- `chevron-down.svg`: strzałka listy rozwijanej (np. wybór motywu), narysowana dla TibiaHelper (MIT). Szara, więc pasuje do każdego motywu.
